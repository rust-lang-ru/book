# Русская версия книги «Язык программирования Rust»

Быстрый старт:
```Shell
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
cargo install mdbook --locked
git clone https://github.com/ip-ram/book.git
cd ./book/rustbook-ru/
mdbook serve
```

## Зачем нужен форк?

Форк заимствует примерно 95% перевода из официального репозитория, официальный репозиторий в свою очередь имеет ряд проблем, на исправление которых нацелен данный форк.

- Перевод может отставать от английского оригинала.
- Возможны отсутствующие примеры кода или целые главы, из-за долго процесса перевода.

Это не означает, что все главы официального проекта ошибочны. Проблема заключается в том, что актуальность перевода, примеров и ссылок необходимо поддерживать отдельно и регулярно проверять.

## Преимущества этого репозитория

Цель этого проекта — сделать русскую версию книги удобной для чтения и максимально согласованной с актуальным английским оригиналом.

Основные преимущества:

- Исправление пропущенных и устаревших примеров.
- Сохранение существующего перевода.
- Проверка качества сборки.
- Открытая возможность для улучшений.
